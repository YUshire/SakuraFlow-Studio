CROSS-PLATFORM DISCOVERY & AUTHORIZED PROFILING

本地智能体自动探测 · 远程 API 接入 · 授权能力画像

SakuraFlow 不会硬编码任何本机路径或臆造模型画像。上线开源后，它会先扫描当前电脑的本地 CLI 智能体（零 API Key 复用你的已登录态），同时允许无本地 CLI 的用户接入任意 Base URL + API Key 远程模型。点击下方授权按钮，系统会向你已启用的智能体发出轻量自检请求，动态生成真实画像。

☁️ 接入远程 API 模型（Base URL + API Key 模式）

即使电脑未安装任何本地 CLI，也可接入 OpenAI / Anthropic 兼容协议的任意远程模型，直接拖入画布并与本地智能体混排协作（密钥仅存于本地 data/remote_agents.json，已加入 .gitignore）。

⚡ 接入 SSH 远程服务器 / GPU 算力节点（远程实验与环境调度接口）

通过系统原生 OpenSSH 连接实验室 GPU 服务器、AutoDL 或云端 Linux 主机：既可一键探测远端 nvidia-smi 显卡算力与 Conda/Python 环境，也可直接作为画布节点或供本地智能体远程调度算力（配置存于本地 data/ssh_hosts.json，已加入 .gitignore）。

🔑 本地 CLI 可选环境变量注入

若某些本地 CLI 未登录桌面端（例如未装 WorkBuddy 时的 dsh），可在此安全注入如 DEEPSEEK_API_KEY，仅对当前子进程生效。

OPEN-SOURCE ARCHITECTURE · DUAL-MODE ENGINE

双轨运行原理与 GitHub 开源设计说明

专为跨平台开源与实战复现设计：无论用户电脑上装了哪些本地 CLI，还是只有几个远程 API Key，都能在 30 秒内零依赖启动并跑通可视化多智能体协作。

轨道 A · 🖥️ 本地 CLI 复用登录态

零 API Key、按需拉起原生进程

自动探测本机已安装的 agy、claude、codex、dsh、gemini、opencode、aider、ollama。运行时按需拉起官方无头 CLI 子进程，直接复用本地合法登录态、反代网关、沙箱与 MCP，干完即退、不占内存、不污染桌面端对话列表。

轨道 B · ☁️ 远程 API 流式接入

Base URL + API Key 零环境门槛

内置零依赖原生 fetch 流式解析器，兼容 OpenAI（支持 reasoning_content 深度思考流）与 Anthropic 协议。无本地 CLI 也能立刻开跑，更支持在同一张画布上将本地 CLI 与远程 API 实体自由混排连线。
